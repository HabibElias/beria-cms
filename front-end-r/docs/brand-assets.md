# Berea identity

The redesign follows the user-supplied **Berea Brand Guidelines (2026)**: the color system on page 20, the typography on page 22, and the icon guidance on page 13.

`public/brand/berea-icon.svg` contains vector paths traced from the emblem embedded in that PDF. The blue background, gold ring, cross, open Bible and hands are retained; the wordmark is excluded. The SVG has a square viewBox and a transparent exterior outside the circular emblem. It contains no embedded bitmap or external image reference. Because the provided PDF contains a raster emblem rather than original vector artwork, the SVG is a vector conversion, not a claim to be the original master artwork. The separate ChatGPT share link could not be retrieved in this environment; confirmation that it shows the same emblem was requested.

Nunito Variable and Noto Sans Ethiopic Variable are self-hosted through their Fontsource packages. Their licenses are included under `public/fonts/`.

Red is reserved for errors and consequential actions. Branded SVG artwork is an existing identity asset, not a new decorative illustration.
